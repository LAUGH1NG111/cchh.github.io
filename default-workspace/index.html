    02 SOFT KEY MAP

    八个软键，一套完整的操作层

    CCBⅡ 主界面

    功能随页面变化，屏幕上方的文字始终与下方实体键一一对应。

    F1提交

    确认 / 执行

    COMMIT & EXECUTE

    修改完参数后按 F1，将配置写入系统并立即生效。没有待保存项时，执行一次状态确认。

    主界面 · 保存在终端按下
    F2导航

    退出 / 返回

    EXIT / RETURN

    从设置页或查询页返回主界面；在主界面按下时，放弃尚未确认的修改。

    返回上级 · 放弃在终端按下
    F3设置

    电空制动

    ELECTRO-PNEUMATIC

    进入 CCBⅡ 电空制动设置菜单，集中调整端位、列车管、制式与补风参数。

    进入设置菜单在终端按下
    F4端位

    操纵端切换

    LEAD / TRAILING UNIT

    在本务（操纵端）与补机（非操纵端）之间切换；切换结果需按 F1 保存。

    本务 / 补机在终端按下
    F5管路

    列车管投入 / 切除

    TRAIN PIPE CUT-IN / OUT

    投入或切除列车管控制通路，当前状态同步显示在屏幕消息栏与压力表中。

    投入 / 切除在终端按下
    F6制式

    货车 / 客车

    FREIGHT / PASSENGER

    切换列车制式。正常行车时应置于货车模式，特殊编组按运用要求选择。

    正常行车 · 货车在终端按下
    F7补风

    补风 / 不补风

    FEED VALVE ON / OFF

    选择列车管补风方式。状态将在确认后写入运行配置，并显示在状态栏。

    补风 / 不补风在终端按下
    F8诊断

    故障 · 记录 · 标定 · 自检

    DIAGNOSTICS CENTER

    打开查询中心，查看活动故障、运行事件、传感器标定值与五项自检结果。

    查询中心在终端按下
    03 BACKLIGHT CONTROL

    从选择到生效，只有四步

    F4 — F7
    03

    确认执行

    F1 · COMMIT
    04

    返回或查询
